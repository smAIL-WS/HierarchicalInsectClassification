# Hierarchical Insect Classification

A fresh, minimal implementation for training hierarchical models on insect datasets.

## Setup and Installation

1. **Environment**: Create a new Python 13.x virtual environment.
2. **Requirements**: Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   *Note: `requirements.txt` does not specify versions to ensure the latest compatible packages are used.*

## How to Run

### 1. Prepare the Data Split
Before training, you must generate the dataset split files.
- Open `insect_hier_class/split_train_test.py`.
- Note: For hyperparameter optimization a train/val/test split is required. For standard training, only train/test splits are required.
- Ensure the line: 
  - `train_val_test_split = False               # Set False to keep original train/test-only behavior` is set correctly.
- If needed, adjust the sampling limits:
  - `max_train_images`: Maximum images per class for training. (1800 for balanced, 18000 for moderately imbalanced, None for full dataset)
  - `max_test_images`: Maximum images per class for testing. (600 for balanced, 6000 for moderately imbalanced, None for full dataset)
- Run the script. This will create a new folder inside `/runs` named with today's date (e.g., `runs/2025-12-20`).

### 2. Configure the Run Date
Once the split folder is created, you must point the trainer to it.
- Open `insect_hier_class/config.py`.
- Update the `RUN_DATE` variable to match the folder name created in the previous step:
  ```python
  RUN_DATE = '2025-12-20'  # Use the date folder generated by the split script
  ```
- You can control the detail of the output logs in `insect_hier_class/config.py`. During Hyperparameter optimization confusion matrices should not be saved due to large file sizes.

```python
# Logging controls in config.py
LOG_PER_CLASS = True     # Set True to save per-class metrics (Precision/Recall/F1)
LOG_PER_LEVEL = True     # Set True to save metrics for each hierarchy level
LOG_CONFUSION = True     # Set True to generate confusion matrix PDFs
```

### 3. Start Training
You can now start the training process:
- **Standard Training**: Run `insect_hier_class/main.py`.
- **Hyperparameter Optimization**: Run `insect_hier_class/main_optuna_full.py` to use Optuna for tuning.

## Project Structure
- `insect_hier_class/`: Core source code.
- `runs/`: Contains dataset splits, hierarchy maps, and training logs (ignored by Git except for structure).
- `requirements.txt`: Minimal dependency list.
